# Filtering

Pipeline: canonicalName + matchType + value; nested terms And/Or; include false = NOT; precision on dates; MultiValue (V3).

Standard post-closing conditions: `operand:operator:value` with = == != > >= < <= like sw ew.

External users: `filter=companyName:'ABCcorp',...`

Personas: personaType.

Always copy operators from the specific OpenAPI page. Spellings differ (exact vs Exact vs Multivalue).
