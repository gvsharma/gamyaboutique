# Task templates and settings

Configuration APIs: Task Template CRUD and Task Settings (global). Paths under `/workflow/v1/templates/task/items`.

Source: [https://developer.icemortgagetechnology.com/developer-connect/reference/task-configuration](https://developer.icemortgagetechnology.com/developer-connect/reference/task-configuration), [https://developer.icemortgagetechnology.com/developer-connect/reference/create-a-template](https://developer.icemortgagetechnology.com/developer-connect/reference/create-a-template)

Subtask templates: POST/GET `/workflow/v1/templates/task/items/{taskTemplateId}/subtasks` with filters (category, dates, tags, pagination, field projection).

**LENDER CONFIGURABLE** per lender workflow design.
