# Conversation logs

Track communications; optional follow-up date; expired follow-up becomes an alert.

Editable log. GET Loan `view=logs|full` includes them (required as of 24.2).

Dedicated: Create via PATCH `action=add` on conversation logs collection; Get All Conversation Logs page exists.

Single-id update/delete pages: confirm in explorer — **not independently fully opened**; general editable-log CRUD is documented at Loan Management level.

Source: [https://developer.icemortgagetechnology.com/developer-connect/reference/loan-conversation-log-1](https://developer.icemortgagetechnology.com/developer-connect/reference/loan-conversation-log-1)
